# VK Music Saver

**1.6.0 beta** — расширение для Chromium-браузеров: скачать один трек по ссылке ВК или кнопкой рядом с песней.

## Установка

1. Скачайте ZIP из раздела Releases и распакуйте его в постоянную папку.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
4. Обновите открытые вкладки ВК. Расширение требует Chromium 120 или новее.

Расширение называется **VK Music Saver**. Это самостоятельный проект, не официальный продукт ВКонтакте.

## Возможности

- Скачивание одного MP3 по ссылке формата `https://vk.ru/audio{owner_id}_{audio_id}`; поддерживается суффикс `_{access_key}`.
- Кнопки загрузки в списках музыки, результатах поиска и поддерживаемых плеерах ВК.
- Размер файла при наведении, прогресс и скорость загрузки, адаптивный интерфейс и светлая/тёмная темы.
- Настройки уведомлений и скорости загрузки. Новая вкладка расширения начинает с пустого поля и нового списка заданий.
- Проверка полученного аудио перед сохранением; обработка истёкших адресов и поддерживаемых перенаправлений CDN.
- **Тестовый режим блокировки аудиорекламы**: шестерня → «Блокировать аудиорекламу (Тест)». По умолчанию выключен. Работоспособность не гарантирована; при ошибках выключите. Также выполняется скрытие определённого промобаннера музыкальной подписки; это зависит от разметки ВК.

Публичные записи сначала запрашиваются без входа. Для остальных используется текущий сеанс в уже открытой вкладке ВК: отдельный пароль расширению не нужен. Удалённые, ограниченные аккаунту или региону записи и HLS не поддерживаются. Файлы сохраняются в папку загрузок браузера с учётом его настроек. Используйте расширение для записей, которые имеете право скачивать.

## Приватность и безопасность

Нет аналитики, сервера разработчика, удалённых скриптов или автоматического выполнения загруженных файлов. Данные сеанса и настройки сохраняются локально. Запросы ВК и его аудиосерверам раскрывают этим сервисам обычные сетевые данные, включая IP-адрес. Подробнее: [PRIVACY.md](PRIVACY.md), [SECURITY.md](SECURITY.md), [AUDIT.md](AUDIT.md).
