# Проверки 1.6.0 beta

В корне проекта выполните `npm test` (Node.js 22+). Установка зависимостей не требуется. Проверки используют синтетические данные и подставные сетевые ответы, не требуют аккаунта ВК и не скачивают настоящую музыку.

- `security.test.mjs`: роли и сообщения, чужие отправители и iframe, адреса и порты, ограничения ввода/ответа/объёма, сигнатуры MP3, manifest и CSP.
- `media.test.mjs`: отклонение HTML даже при ложном MIME, оборванный файл, сохранение точных байтов, дробление потока и финальный прогресс.
- `size.test.mjs`: HEAD, резервный Range, полный размер вместо одного байта, ошибки и неизвестный размер.
- `player.test.mjs`: текущая запись и её смена, синтетический ключ доступа, отсутствие записи, отказ для рекламы и роли команд.
- `no-empty-progress.test.mjs`: отсутствие карточки на нулевых байтах, появление при получении данных.
- `adblock.test.mjs`: точный рекламный домен/путь, ограничение media и инициатором ВК, включение/выключение и ошибка API правил.
- `transport.test.mjs`: проверка начального и конечного домена, отмена ответа и принудительный запрет передачи credentials аудиосерверу.

Эти проверки не заменяют ручное тестирование интерфейса в браузере. После установки проверьте скачивание доступного трека, смену песни в плеере, ошибку недоступной записи, уведомления, настройки и оба оформления. Блокировщик по умолчанию выключен; тестируйте его отдельно.
